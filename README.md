# Spotify Style for YouTube Music

Modifies YouTube Music to look like Spotify, featuring a full-screen Canvas player and TV Dashboard layout.

## Installation

1. Download or clone this repository.
2. Open your browser extension manager:
   - **Chrome**: `chrome://extensions/`
   - **Edge**: `edge://extensions/`
   - **Brave**: `brave://extensions/`
3. Enable **Developer mode** (top right toggle).
4. Click **Load unpacked** and select the project folder (`youtubeExtension`).
5. Open [YouTube Music](https://music.youtube.com)
